Bilingual Meeting Copilot V0.1

第一版聚焦 PRD 里程碑 21.1：可演示、可见、可测试。通过手动输入会议英文模拟实时转写，完成字幕缓存、知识库检索、主动触发 AI 回复、右侧双语建议的闭环。

实现路径选择

推荐

A. Web MVP + 本地后端

用 React/Vite 做可见前端，用 FastAPI 做本地服务，保留 Electron 接入边界。

  • 最快形成可演示页面
  • 后端模块边界清楚，便于后续接音频和 Electron
  • 不用先解决桌面打包和系统音频权限

B. Electron 一步到位

直接搭 Electron + React + Python 服务，贴近最终 PRD 形态。

  • 架构更接近桌面产品
  • 首版依赖和调试复杂度更高
  • 音频权限和打包会拖慢 MVP

C. 纯前端演示原型

只做浏览器页面和 mock 数据，后端后续再补。

  • 界面最快可见
  • 无法验证知识库和上下文真实逻辑
  • 安全边界和 API Key 管理不足
